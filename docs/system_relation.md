# Continuous certification relation

The system entry is `scripts/run_efficiency_benchmark.py --config configs/system_efficiency.yaml`. The unified implementation resides in system_models.py, system_relation.py, system_runtime.py and run_system_efficiency.py. The larger-model entry delegates to this same implementation. The legacy mock session remains a development API and is not used for measurements.

Each party reads only its own prepared input file. The owner registers a blinded model commitment; each holder registers a Merkle root for each of two full population partitions. Registration workers require contiguous partition indices covering the configured population. Record hashes bind holder, stratum, local index, nonce, features, label and protected attribute. Merkle verification uses the selected record's path to the original full partition root.

Poseidon parameters and circuit definitions come from the locked co-circom source distribution under external/co-snarks-src. Fold hashing uses Poseidon with sixteen inputs: a domain-and-length-initialized chaining state and fifteen data elements, padding the final block with zeros. Domain 1 identifies model parameters and the blinding nonce; domain 2 identifies records. Internal Merkle nodes use Poseidon with two inputs. Parameters, paths and record fields are BN254 scalar-field elements.

Three fresh random 256-bit contributions are committed before any contribution is revealed. Commitments bind the party index and unique session identifier. SHA-256 derives the challenge from all contributions. Counter-mode SHA-256 and rejection sampling select records without replacement using a partial Fisher-Yates shuffle, independently within each stratum. The verifier recomputes the entire challenge and sample.

The public input vector, including circuit outputs, is `[accepted, sessionBinding, tag, modelCommitment, roots[4], indices[m]]`. The tag is SHA-256 of the canonical registration and challenge, reduced modulo the BN254 scalar field. The session binding is Poseidon(tag, modelCommitment). Roots are ordered by stratum then holder. Indices encode stratum, holder and partition-local index. The verifier checks this vector against the separately retained public registration and challenge before invoking Groth16 verification. The verifier reads only public files and the verification key.

Private circuit inputs contain model parameters and nonce, sampled records and their Merkle paths, and predictions exported by MASCOT. The circuit independently recomputes inference and compares each result to the MASCOT prediction. Model coefficients and features are constrained to -1, 0 or 1. Labels and protected attributes are bits. All model arithmetic is exact integer arithmetic with scale zero and threshold zero. Quadratic activation applies to every hidden MLP layer. The SVM includes a bias, every linear feature, and each quadratic pair i<=j once in lexicographic order. Per-layer bounds derive from the maximum coefficient and input magnitudes; all supported accumulator bounds fit below signed 63-bit comparison width and below the field modulus.

The formal policy uses delta=0.05, minimum population accuracy 0.75, maximum population violation rate 0.25, and epsilon=sqrt(log(4/delta)/(2*n)) for n=64 samples per stratum. Four one-sided Hoeffding bounds cover correctness and violations in both strata; the bound is conservative for sampling without replacement. The resulting circuit and MPC thresholds are at least 60 correct and at most 4 violations per stratum. Equal configured stratum populations give weights 0.5 and 0.5. These synthetic workloads measure efficiency, not predictive utility on held-out real data.

MASCOT runs with three distinct participant working directories and online preprocessing over the BN254 scalar field. Input owners are supplied as public runtime indices. Input sharing completion is observed from all three line-buffered participant logs; time up to the last observed marker is assigned to input_sharing_s. Its polling and startup overhead is included. The remaining process interval is assigned to mpc_s. Conversion begins only after all participants exit successfully and explicit masked-opening MAC checks complete.

The bridge decodes authenticated MP-SPDZ persistence files and converts each local additive share plus its predecessor's additive share into the replicated co-circom input layout. Three separate converter processes perform this operation. No complete clear witness is reconstructed. Co-witness generation and Groth16 proving use matching O2 circuit optimization. The strongest supported end-to-end corruption claim is one passive corruption, reflecting REP3 and trusted local file handoff; the bridge does not add active integrity to REP3 or authenticate arbitrary later file modifications.

Single-prover controls run after the directly measured first-use and session intervals. They assemble clear inputs only in their separate control directory and use the same circuit, proving key and expected public statement. They independently derive model predictions with the integer reference. Their witness is never fed back into the system path.

The formal setup uses SRS files listed in the pinned snarkjs release README, verifies their published BLAKE2b digest, then performs circuit-specific Groth16 setup and a fresh random contribution. Setup includes acquisition or cache verification and does not claim SRS generation. Source URLs, cache reuse and checksums are recorded. Functional checks may instead generate a local test SRS, and are excluded from table export. The configured SRS resource budget is at most power 21; larger requirements retain an explicit resource-budget reason.

Setup, first-use and session intervals use the same coordinator monotonic clock. Raw subprocess commands, exit codes, logs and peak aggregate RSS are retained. Entropy arguments are redacted from command receipts. Process trees are killed on timeout or memory-budget violation. The fixed formal budget is 180 seconds per subprocess stage and 10 GiB aggregate RSS. File caches are not cleared. With one session, sample standard deviation is undefined and stored as null.
